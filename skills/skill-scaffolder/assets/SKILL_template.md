# {{skill_name}}

Этот skill создан с помощью `skill-scaffolder`.

## Назначение

Кратко опиши, для чего предназначен этот skill, в каких сценариях его следует использовать и как он помогает агенту.

## Структура

- `SKILL.md` — текущий файл с инструкциями и метаданными.
- `scripts/` — опциональные исполняемые скрипты (чаще всего Python).
- `references/` — дополнительная документация, шпаргалки, примеры.
- `assets/` — шаблоны, промпты, текстовые ресурсы.

## Рекомендации по наполнению

- Заполни этот файл детальными инструкциями:
  - какие задачи решает skill;
  - как агент должен его использовать;
  - какие ограничения и предположения есть.
- Добавь полезные материалы в `references/` (например, примеры, гайды, чек-листы).
- Используй `assets/` для шаблонов (промпты, шаблоны писем, отчётов и т.п.).
