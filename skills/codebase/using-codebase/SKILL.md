# Using Codebase

This pack produces a read-only understanding of an existing codebase. Nothing here modifies files.

## Pick the inner skill by what you must deliver

| Deliverable | skills_load |
|---|---|
| A broad, evidence-backed map of an unfamiliar codebase | `codebase:project-overview` |
| A trace of one specific behavior or flow through the code | `codebase:project-investigation` |

## If understanding is only a step

If understanding the code is a step toward changing it, this pack covers the understanding step only. Once you have what you need, return to the original task.
