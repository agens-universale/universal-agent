# duckduckgo_search — ddgs-mcp

Интеграция [ddgs-mcp](https://pypi.org/project/ddgs-mcp/) — MCP-сервер
метапоиска DuckDuckGo (библиотека [DDGS](https://github.com/deedy5/ddgs)).
Ставится из PyPI через `recommended_mcp/install.py`.

## Требования

- **Python 3.10–3.13** (ограничение пакета `ddgs-mcp`).
- **Активный venv агента** перед запуском `install.py`.
- Сетевой доступ при установке (`pip install ddgs-mcp`).

## Установка

Из корня репозитория:

```bash
python recommended_mcp/install.py
```

Или вручную:

```bash
pip install ddgs-mcp==0.1.0
```

После установки в PATH активного venv появится команда `ddgs-mcp`.

## Подключение к агенту

Скопируй содержимое `agent_config.snippet.yml` в секцию `mcp-servers:` твоего
`config.yml` агента.

## Запуск

Отдельного запуска не требует — агент сам спавнит `ddgs-mcp` по stdio
при первом вызове тула. `run.py` этот MCP пропускает.

Для отладки вручную:

```bash
ddgs-mcp
```

HTTP-режим (daemon, не используется snippet'ом по умолчанию).
По умолчанию слушает `http://127.0.0.1:10090/mcp` — этот URL указывается
в `config.yml` агента, сервер нужно запустить **до** агента:

```bash
ddgs-mcp --http
```

## Тулы

| Тул | Назначение |
|---|---|
| `web_search` | Веб-поиск по нескольким движкам |
| `news_search` | Поиск новостей с фильтром по времени |

## Переменные окружения и порты

Не путать **два разных «порта»**:

| Что | Порт / URL | Зачем |
|---|---|---|
| MCP-сервер в HTTP-режиме (`ddgs-mcp --http`) | `10090` → `http://127.0.0.1:10090/mcp` | Куда **агент** подключается как MCP-клиент. Только для HTTP-транспорта, не для stdio-snippet'а. |
| `DDGS_PROXY` (исходящий прокси поиска) | любой, часто `7890` | Куда **библиотека DDGS** шлёт HTTP-запросы к поисковикам. Это не порт MCP-сервера. |

`7890` в примерах — типичный порт локального HTTP-прокси (Clash и аналоги).
Подставь свой хост и порт, если прокси другой (`8080`, `10809` и т.д.).
Если прокси не нужен — `DDGS_PROXY` не задавай.

В **stdio-режиме** (snippet по умолчанию) порт `10090` не нужен — агент сам
спавнит `ddgs-mcp` как subprocess. `DDGS_PROXY` к транспорту не привязан:
если поиск без прокси не работает, задавай его и в stdio, и в HTTP-режиме.

| Переменная | Когда нужна | Пример |
|---|---|---|
| `DDGS_PROXY` | Поиск должен идти через HTTP-прокси (блокировки, корп. сеть) | `http://127.0.0.1:7890` |

Задавай в блоке `env:` сниппета или в shell перед запуском агента / `ddgs-mcp --http`:

```yaml
env:
  DDGS_PROXY: http://127.0.0.1:7890   # свой URL прокси
```

## Обновление

Поменяй пин `install.package` в `recommended_mcp/config.yml`
(например `ddgs-mcp==0.2.0`) и снова запусти `python recommended_mcp/install.py`.
