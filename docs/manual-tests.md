# Ручные тесты

Здесь то, что автоматический набор проверить **не может**: живые MCP-серверы,
настоящий браузер, реальная модель, поведение процессов во времени. Всё
остальное закрыто `uv run pytest` — см. [testing.md](testing.md).

Правило отбора: если проверку можно написать на `ScriptedBackend`, ей здесь не
место, она идёт в pytest. Сюда попадает ровно то, где отказ проявляется только
на живом внешнем участнике.

Стенд — `/Users/nikita/gc-core-acceptance`, конфиг у него свой
(`gc-config.yml`).

## Прежде чем мерить: убедиться, что меряете СВОЙ код

Единственная ошибка, которая обесценивает весь прогон разом и ничем себя не
выдаёт.

Стенд ставит `gc-core` **копией**, не editable. Хуже: его `pyproject.toml`
какое-то время был пришпилен к git-ревизии УДАЛЁННОЙ ветки —

```toml
gc-core = { git = "ssh://…/universal-agent", subdirectory = "packages/core", rev = "feat/async-core" }
```

— и любой `uv run` втихую откатывал ручную установку из пути на последний
запушенный код. Замер при этом проходил нормально и показывал правдоподобные
числа. Приёмку 26.08 пришлось перепроверять целиком именно поэтому.

Сейчас источник переключён на локальный путь. Три правила всё равно
действуют:

1. `--reinstall` **недостаточно** — uv отдаёт колесо из своего кэша. Нужен
   `--no-cache`:

   ```bash
   cd /Users/nikita/gc-core-acceptance
   VIRTUAL_ENV=$PWD/.venv uv pip install --reinstall --no-cache --no-deps \
       "gc-core @ /Users/nikita/main_agent_core/packages/core"
   ```

2. Запускать **`.venv/bin/python`**, а не `uv run`: второй синхронизирует
   проект и может подменить сборку.

3. Каждый скрипт стенда зовёт `freshness.assert_fresh()` первой строкой. Не
   убирайте: проверка стоит копейки и падает громко.

Быстрая сверка вручную:

```bash
.venv/bin/python -c "from freshness import assert_fresh; assert_fresh(); print('свежее')"
```

## Мерки: две ловушки, на которые мы уже попались

**Отношение к одиночному прогону не меряет параллельность.** На живой модели
длина ответа зависит от промпта, и одиночный прогон спрашивает своё, а пара —
своё. Замер 26.08 дал 1,90× при полном перекрытии. Правильная мера — отношение
к МЕДЛЕННОМУ ИЗ ПАРЫ: полное перекрытие даёт `pair == max(individual)`,
очередь — `pair == sum(individual)`.

**Один худший разрыв — это шум.** Хватит паузы GC, чтобы «провалить» порог.
Смотреть медиану и процентили: если цикл действительно отняли, страдает не один
тик, а хвост целиком.
