На что жаловался Sonar и что это теперь ловит

Каждая строка — тип ошибки из отчёта Sonar. Отдельные замечания по файлам — в следующем разделе.

  • Что не так — суть правила простыми словами и код правила Sonar.
  • Было — сколько раз Sonar нашёл такую ошибку в нашем коде.
  • Что сделали — исправлено не исправляем (осознанное решение) так задумано (не ошибка, есть обоснование) неприменимо (файла больше нет или он вне репо).
  • Теперь — ловится до коммита: новая такая ошибка не пройдёт pre-commit, и до Sonar не доедет. не ловится локально: для этого нужен анализ типов, такие места разобраны вручную.

Что поймали по дороге

  • Ретраи chat/completions были мертвы. Рефакторинг под сложность унёс декоратор @retry_with_backoff_async с публичной функции на внутренний хелпер, и запросы к модели перестали повторяться, включая 404 из develop. Декоратор возвращён, границу держит test_connect_backend_retry_boundary.
  • Автофикс F401 обезвредил тест. Удалил import внутри pytest.raises(SystemExit), который и был проверяемым действием; тест позеленел и перестал проверять. Импорт возвращён, тесты выведены из-под ruff check (формат по ним остался). Скан 340 удалённых импортов других таких случаев не нашёл.
  • Автофикс RUF100 снёс 27 пояснений. Вместе с «лишними» # noqa ушли и объяснения вроде «shell намеренно» у subprocess. Возвращены обычными комментариями.
  • Недостижимый код после нашего же рефакторинга. 21 строка старого тела функции в arg_decorators после нового return — её нашла новая проверка мёртвого кода.
  • NOSONAR не там, где его видит Sonar. В transport.py он стоял строкой выше проверки, а в os_backend_client попал внутрь скрипта, который уходит в контейнер. Оба поправлены.
  • gc-serve --help поднимает сервер. Команда не разбирает аргументы и сразу стартует без авторизации на 0.0.0.0:8000. Найдено при проверке команд; в этой задаче не чинилось.

  • ruff как единый линтер и форматтер — де-факто стандарт 2026 года, заменяет black, isort и flake8 с плагинами; в хуках сначала ruff check --fix, потом ruff format источник
  • pre-commit и prek — одна конфигурация .pre-commit-config.yaml; prek — совместимая реализация на Rust, быстрее и без Python источник
  • Локальные хуки через uv run — версии инструментов из uv.lock, как в CI; за хуками не нужно ходить на GitHub источник
  • Ratchet вместо амнистии — старый долг замораживается снимком complexipy, новое блокируется, улучшения сужают снимок автоматически источник

  • Дублирование — pylint duplicate-code — межфайловый поиск копипасты, порог 10 строк как у CPD Sonar источник
  • Массовое форматирование — вне blame — хеш механического коммита в .git-blame-ignore-revs источник
