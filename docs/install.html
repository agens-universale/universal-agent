Установка GigaCode Universal Agent

Агент для выполнения задач в терминале. Установка одной командой, без клонирования репозитория. Перед началом получите у команды GigaCode адрес сервера и токен доступа — понадобятся на шаге 4.

  1. 1

    Установить Git и uv

    Одноразовый шаг. Откройте терминал и выполните команды для своей системы.

    winget install Git.Git powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
    # Git: macOS → xcode-select --install · Linux → sudo apt install -y git curl -LsSf https://astral.sh/uv/install.sh | sh

    После установки перезапустите терминал.

  2. 2

    Установить агента

    uv tool install "git+https://gitverse.ru/gigacode-ai/background-agent@feat/agent-instructions-and-gc-guard"
    !
    В корпоративной сети Сбера добавьте в конец флаг --system-certs — иначе установка прервётся на проверке сертификатов.

    Устанавливаются две команды: gc-ua — основной режим с интерфейсом, и gc-cli — для разовых запросов.

  3. 3

    Создать конфиг

    gc-ua

    Первый запуск создаёт файл настроек и останавливается с подсказкой — это нормально. Файл: ~/.gc/config.yml.

  4. 4

    Вписать адрес и токен

    Откройте config.yml в любом редакторе и измените:

    backend: completions_url: "ВАШ_АДРЕС/v1/chat/completions" use_ssl: true # true, если адрес https:// chat_completion_headers: Authorization: "Bearer ВАШ_ТОКЕН" agent: model: "имя_модели" # если выдали

    Сохраните. Токен — как пароль, не пересылайте.

  5. 5

    Запустить

    gc-ua # интерфейс gc-cli -q "Привет, что ты умеешь?" # разовый запрос
  6. 6

    MCP-серверы — по желанию

    Подключаемые расширения: поиск, документы, браузер и др. После установки подключаются автоматически.

    gc-mcp install # все рекомендованные gc-mcp install duckduckgo_search # один по имени gc-mcp list # доступные / установленные gc-mcp remove duckduckgo_search # удалить по имени gc-mcp remove --all # удалить все gc-ua -a # запуск со всеми
    MCP-серверЧто умеет
    duckduckgo_searchПоиск в интернете — веб-страницы и новости.
    officeЧтение и создание Word, Excel, PowerPoint.
    scienceПоиск научных публикаций (PubMed, arXiv и др.).
    computerАвтоматизация Windows-интерфейса (только Windows).
    browser_playwrightУправление браузером — сайты, формы, клики.
i
Если не работает. git/uv не найдены → повторите шаг 1 и перезапустите терминал. Падает на сертификатах → флаг --system-certs. Ошибка 401 → проверьте адрес и токен в конфиге.
