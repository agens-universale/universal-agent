# Что сделано поверх master

Сводка всех изменений ветки `feat/agent-instructions-and-gc-guard` (вместе с родительской `feat/mcp-install-ux-stream`) относительно `master`.

- **Объём:** 211 коммитов, 220 файлов, +15993 / −744 строк (merge-base `a14b376`).
- **Линия веток:** `master` → `feat/mcp-install-ux-stream` (упаковка, MCP, стриминг, turn-contract) → `feat/agent-instructions-and-gc-guard` (слои инструкций, защита `.gc`, `/init`, TUI confirm, страница установки).
- Каждая строка — отдельная **фича**, **улучшение** или **фикс** (агрегировано по смыслу, не по коммитам).

**Колонки:** что · функция (что даёт) · зачем (мотивация) · флаг/конфиг и дефолт · где работает.
**«Где»:** `все` = все режимы (CLI/server/swarm/TUI); `TUI` = только в TUI; `CLI` = инструмент/команда; `установка` = на этапе установки.
`—` в колонке флага = тумблера нет, работает всегда. Дефолт выделен **жирным**.
