## 1. Проблема

Сейчас reasoning отображается двумя способами, и оба неудачны:
1. **Полный текст рассуждения** рисуется постоянной строкой трейса (`.line-think`): reasoning/`<think>` → `TraceEvent(kind="system", title="think")` → строка с полным контентом ([trace_mapper.py:145-154](src/tui/services/trace_mapper.py#L145), [main.py:742-748](src/tui/screens/main.py#L742)). Это шумно и остаётся в истории.
2. `ThinkingIndicator` крутит ротацию «думаю/размышляю…» **по таймеру 250мс независимо от модели** — то есть **не доказывает**, что модель жива (спиннер крутится, даже когда бэкенд уже завершил/завис).

Нужно: reasoning показывать **только индикатором** (без текста), и индикатор должен **доказывать реальный прогресс модели**, а не крутиться впустую.

## 2. Решения (зафиксировано в brainstorming 2026-06-16)

| Вопрос | Решение |
|---|---|
| Контент reasoning | **Убрать.** Текстом не показываем, в историю не сохраняем. |
| Форма | **Claude-style одной строкой** (как скрины 3,4 у Claude). |
| Ротация фраз | **Не трогаем** — все текущие фразы живут как есть, крутятся всегда. |
| Где смысл reasoning | **В теге**, не в слове: `· размышление` → `· обдумал за Ns` (липкий). Нет reasoning — нет тега. |
| Пруф живости | **Счётчик `↓ N`** — считаем принятые из стрима символы/≈токены **сами**, не из `usage` (на SGLang `usage=None`). Растёт = модель реально стримит. |
| Стопор-плашка «жду сервер» | **Не делаем** — счётчик `↓ N`, который не растёт, + тикающее время `(Ns)` уже это показывают. Лишнее. |
| Ответ (answer) | Продолжает **стримиться живьём** (StreamBlock), это смысл стриминга. Только reasoning уходит в индикатор. |
| Токены из backend `usage` | Не используем (часто `None`). Счётчик — наш. |

## 3. Итоговый вид индикатора

Порядок (как у Claude `32s · ↓ 1.6k tokens · thinking`): **время · ↓ счётчик · состояние**.

```
⠹ кручу шестерёнки…  (8с · ↓ 1.2k токенов · размышление)      ← фаза reasoning
⠼ анализирую…        (31с · ↓ 3.3k токенов · обдумал за 6с)   ← reasoning кончился, тег липкий
⠴ собираю мысли…     (40с · ↓ 4.1k токенов)                   ← reasoning не было — только счётчик
```

- **Глагол** (`кручу шестерёнки…`) — существующая ротация `ThinkingIndicator`, **без изменений**. Это «флер/жив», не семантика.
- **`(Nс)`** — существующий elapsed; **единица меняется `s → с`** (кириллица), чтобы совпасть с тул-строками (`running · Nс`). Подробнее — §5.1.
- **`↓ N токенов`** — наш счётчик принятого из стрима (≈токены). Главный пруф живости. Идёт **сразу после времени**.
- **`· размышление`** — показывается, пока идёт reasoning (приходят think-дельты, ответа ещё нет). Крайний справа.
- **`· обдумал за Nс`** — заменяет `размышление`, когда reasoning закончился; держится до конца такта (как «thought for 6s» у Claude).

## 4. Источник данных — `StreamSink` (расширяем)

`StreamSink` (с ветки стриминга) уже копит think/answer. Добавляем потокобезопасно (под тем же lock):
- `chars: int` — суммарно принятых символов (think + answer) за текущий такт; для счётчика.
- `reasoning_started_at: float | None` — монотоника первого think-дельта.
- `reasoning_ended_at: float | None` — монотоника первого answer-дельта **после** think (или сброс такта).
- Методы для индикатора:
  - `progress_units() -> int` — ≈токены = `chars // 4` (грубо; точность не нужна).
  - `reasoning_state() -> tuple[str|None, float|None]` — `("thinking", None)` пока reasoning идёт; `("done", duration_sec)` после; `(None, None)` если reasoning не было.

`push(kind, text)`:
- `kind == "think"` → если `reasoning_started_at is None`: ставим его; `chars += len(text)`.
- `kind == "answer"` → если был think и `reasoning_ended_at is None`: ставим `reasoning_ended_at = now`; `chars += len(text)`.
- `kind == "reset"` (начало попытки/такта, уже есть на ветке) → обнуляем `chars`, `reasoning_started_at`, `reasoning_ended_at` (и буферы think/answer как сейчас).

Время берём `time.monotonic()` в `push` (worker-поток) — это нормальный код, не Workflow-скрипт; ограничений нет.

## 5. `ThinkingIndicator` (расширяем рендер)

Индикатор на тике 250мс читает `app._stream_sink` (как StreamBlock в [main.py:1161](src/tui/screens/main.py#L1161)) и строит хвост строки **в порядке `(время · ↓ счётчик · состояние)`**:
1. elapsed `({elapsed}с)` — см. §5.1.
2. если `progress_units() > 0` → ` · ↓ {fmt(units)} токенов` (`fmt`: `<1000 → "N"`, `≥1000 → "N.Nk"`).
3. состояние reasoning:
   - `reasoning_state()` == `("thinking", _)` → ` · размышление`;
   - `("done", d)` → ` · обдумал за {round(d)}с`;
   - `(None, None)` → ничего.
- глагол/спиннер/ротация — **без изменений** (`PhraseRotator`, `MORPH_FRAMES`).

Когда стриминга нет / `backend.stream:false` / headless → sink пуст → хвост (счётчик/состояние) не добавляется, индикатор = `⠋ <фраза>… (Nс)`.

### 5.1 Единица времени: `s → с` (везде)

Сейчас разнобой: `ThinkingIndicator` рисует `({elapsed}s)` (латинская `s`, [thinking_indicator.py:164](src/tui/widgets/thinking_indicator.py#L164)), а `ToolCallRow` — `running · {N}с` (кириллическая `с`, [tool_call_row.py:137](src/tui/widgets/tool_call_row.py#L137)). Унифицируем на **`с`**:
- правим **только** `ThinkingIndicator`: `({elapsed}s)` → `({elapsed}с)`;
- `ToolCallRow` **не трогаем** — там уже `с`.

(Если позже захотим «сек» — меняем оба места; пока минимальная правка.)

**Никакого нового виджета** — расширяем `_render_text` существующего `ThinkingIndicator`; sink передаём в него (ссылкой на `app._stream_sink` или через сеттер на каждом показе).

## 6. Убираем контент reasoning

1. **Строки трейса:** в [trace_mapper.py:145-154](src/tui/services/trace_mapper.py#L145) ветка `typ in ("reasoning", "think")` → возвращать `None` (строка `.line-think` больше не создаётся). Соответствующий рендер в [main.py:742-748](src/tui/screens/main.py#L742) становится мёртвым — убрать.
2. **Инлайновый `<think>` в тексте ответа:** при рендере agent-строки вырезать `<think>...</think>` (в т.ч. незакрытый, как в `format_stream_block`), чтобы рассуждение не утекало в видимый ответ. Точка — там, где собирается `summary` для `kind="agent"` (assistant text).
3. **StreamBlock / `format_stream_block`:** убрать think-хвост — показывать **только answer** (reasoning ушёл в индикатор). Обновить тесты `test_stream_sink.py` (формат больше не содержит «думаю… <tail>»).

## 7. Краевые случаи

| Случай | Поведение |
|---|---|
| reasoning есть, потом ответ | `размышление` → `обдумал за Nс` (липко до конца такта). |
| reasoning есть, потом сразу tool-call (без answer-текста) | `размышление` до конца такта; `обдумал за` не выставляется (нет answer-дельты) — на сбросе такта тег уходит. Допустимо. |
| reasoning нет вообще | Тега нет; только `(Ns · ↓ N)`. Чинит «думаю при чтении файлов» на уровне тега (слово-флер остаётся — принято осознанно). |
| Стрим оборвался (сервер «висит») | Счётчик `↓ N` не растёт, `(Ns)` тикает → пользователь видит «данных нет». Отдельной плашки нет (решено). |
| Нет стриминга / headless | Индикатор как сейчас, без хвоста; reasoning-строки всё равно подавлены. |
| retry/`reset` посреди такта | `reset` обнуляет счётчик и тайминги — партиал не задваивается (логика reset уже на ветке). |

## 8. Тесты (TDD)

- **StreamSink:** `push("think",…)` ставит `reasoning_started_at` и растит `chars`; первый `push("answer",…)` после think ставит `reasoning_ended_at`; `reasoning_state()` даёт `thinking`→`done`+duration; `reset` всё обнуляет; `progress_units()` = chars//4.
- **format_stream_block:** больше **не** содержит think-хвост (только answer) — обновить существующие кейсы.
- **ThinkingIndicator:** при sink в фазе thinking хвост `· размышление · ↓ N`; в фазе done — `· обдумал за Ns · ↓ N`; при пустом sink — хвоста нет.
- **trace_mapper:** событие `typ="reasoning"`/`"think"` → `None` (строка не создаётся).
- **Инлайн-`<think>` стрип:** agent-текст с `<think>…</think>` рендерится без него.
- Прогон точечный (`uv run pytest tests/tui/...`), в изоляции (флапы снапшотов).

# Ревизия 2 (2026-06-16): показывать reasoning компактной строкой

**Мотив.** Живой прогон на gigacode/SGLang (тред `f81aca06`) показал: модель **reasoning-доминантная** — рассуждение лежит **инлайном `<think>…</think>` внутри `content`** (отдельного `reasoning_content` НЕТ), и на ~62% тактов (13 из 21) прозы-ответа после `</think>` НЕТ вовсе. При полном сокрытии reasoning (исходный дизайн) экран почти пустой: только счётчик + tool-calls. Решено reasoning **показывать**, но компактно.

Перекрывает: §3/§5 (убираем словесный тег «· размышление»), §6.3 (StreamBlock не «answer-only», а показывает строку-мысль во время reasoning). Остаётся: §4 (счётчик/тайминги), §5.1 (`s→с`), §6.1 (нет постоянных `.line-think` строк в истории), §6.2 (`<think>` срезан из видимого ответа).

## R2.1 Детект reasoning из ОБОИХ источников (правка парсера)
В `assemble_streamed_completion` (`src/utils/chat_completions_stream.py`) добавить **stateful-разбор инлайнового `<think>`** по потоку `delta.content`:
- хранить флаг `in_think` между чанками (теги `<think>`/`</think>` могут приходить разорванными);
- текст **внутри** `<think>…</think>` → `on_delta("think", …)`; текст **снаружи** → `on_delta("answer", …)`;
- `delta.reasoning_content` (если когда-то появится) → тоже `on_delta("think", …)` (уже так).
- Собранный финальный `message.content` остаётся **как пришёл** (с инлайновым `<think>` внутри) — downstream/`_extract_assistant_text` его и так срезает; меняем только маршрутизацию **дельт** для on_delta.

Так `StreamSink._think` наполняется реальным рассуждением → `reasoning_state()` даёт `thinking`/`done`, а `_think` доступен для показа.

## R2.2 Строка-мысль — одна dim/italic строка НАД индикатором
Источник — `StreamSink`. Добавить `StreamSink.reasoning_tail(maxlen: int) -> str`: последние `maxlen` символов `_think` одной строкой (переводы строк схлопнуть в пробел, префикс «…» если обрезано). 

`StreamBlock` (позиция над `ThinkingIndicator`, уже так монтируется) показывает:
- **фаза thinking** (есть think, ответа ещё нет) → одну строку `⋮ <reasoning_tail>` (dim/italic, глиф `⋮`), катится по мере стрима;
- **фаза answer** (пошёл текст ответа) → текст ответа, как сейчас (`format_stream_block(answer=…)`).

`format_stream_block` поэтому снова принимает и think, и answer (ревизует §6.3): если answer пуст, но есть think → вернуть `⋮ <tail>`; иначе → answer (с вырезанным `<think>`). Точная сигнатура — на этапе плана.

**Стиль/отступы:** строка-мысль — `.line-think`-подобный стиль (dim/italic) + **вертикальные margin сверху/снизу** (как у трейс-строк), чтобы не слипалась.

## R2.3 Индикатор — БЕЗ словесного тега reasoning
Во время reasoning индикатор **просто крутит фразы** (ротация как есть) + `(Nс · ↓ N токенов)`. Словесный тег «· размышление» **убираем** (его роль теперь у строки-мысли — иначе дублирование). Тег **`· обдумал за Nс`** (после reasoning, липкий до конца такта) — **оставляем** (факт+длительность, не дублирует). Итог:
```
reasoning:  ⠹ кручу шестерёнки…  (8с · ↓ 703 токенов)            + строка-мысль над
answer:     ⠼ анализирую…        (31с · ↓ 3.3k токенов · обдумал за 6с)
без reason: ⠴ собираю мысли…     (40с · ↓ 4.1k токенов)
```
→ в коде убрать ветку `if r_state == "thinking": parens += " · размышление"`; ветку `done` оставить.

## R2.4 Жизненный цикл и порядок (ask_human)
Строка-мысль = тот же эфемерный `StreamBlock`: монтируется внизу **над индикатором**, гасится `_clear_stream_block()` при канонной строке / границе шага / stop. Поэтому она **никогда не оказывается выше зафиксированных строк** (в т.ч. отвеченного ask_human) — порядок сохраняется автоматически. Проверить тестом сценарий «ask_human отвечен → новый шаг с reasoning → строка-мысль внизу, не выше ask_human-блока».

## R2.5 Краевые случаи (ревизия §7)
- reasoning есть → строка-мысль катится; индикатор без тега; после → `обдумал за Nс`.
- reasoning есть, ответа нет (tool-call) → строка-мысль до конца шага, потом гаснет; `обдумал за` не выставится (нет answer) — допустимо.
- reasoning нет → строки-мысли нет; индикатор `(Nс · ↓ N)`.
- стрим оборвался → `↓ N` не растёт, строка-мысль замирает на последнем хвосте, время тикает (сигнал «данных нет»).
- нет стриминга/headless → ни строки-мысли, ни хвоста; индикатор `(Nс)`.

## R2.6 Тесты (ревизия §8)
- **Парсер:** инлайн-`<think>` через границы чанков → правильное разбиение на think/answer (на реальном сэмпле из треда `f81aca06`); `</think>` в середине; незакрытый `<think>` (всё в think).
- **StreamSink:** `reasoning_tail(maxlen)` — обрезка/схлопывание строк/префикс «…».
- **StreamBlock:** фаза thinking → `⋮ <tail>`; фаза answer → answer; пусто → пусто. (обновить тесты, что делали answer-only).
- **Индикатор:** во время thinking — БЕЗ «размышление»; после — `обдумал за Nс`; счётчик есть.
- **Порядок:** ask_human-сценарий (строка-мысль внизу, не выше).
