# Дизайн: индикатор-статус вынести из скролла в фиксированную строку

Дата: 2026-06-26
Статус: дизайн (ожидает ревью)

## Проблема

После перехода на событийную перерисовку стрима (~12 fps) строка-индикатор агента
(«думаю…», «сверяюсь…», «сжимаю…») визуально мерцает. Корень не в самой анимации
индикатора, а в том, что он — **последний ребёнок скролл-контейнера `#trace`**, прямо
**под** растущим стрим-виджетом ([main.py:642](../../src/tui/screens/main.py#L642)
`trace.mount(indicator)`; строки трейса монтируются `before=self._thinking`). На каждый
прирост стрима `#trace` делает не-атомарный reflow: на один кадр новая строка ответа
рисуется **поверх** строки индикатора (на её старой позиции), затем трейс «поднимается» и
индикатор переезжает. При ~12 fps это транзиентное наложение видно как мерцание.

## Решение

Вынести индикатор **из скролл-потока `#trace`** в отдельную **фиксированную строку**
`#indicator-bar` в `#root`, **между `#trace` и `#input-row`** (статус-строка под разговором,
над вводом). Стрим растёт и скроллится в `#trace`, индикатор — в своём регионе; наложиться
им негде → транзиент исчезает. Жизненный цикл индикатора не меняется — меняется только
родитель монтажа.

## Компоненты и изменения (минимальные — «куда монтируем»)

### 1. `compose()` ([main.py:174-186](../../src/tui/screens/main.py#L174))
Добавить контейнер между `#trace` (180) и `#input-row` (181):

```python
            yield VerticalScroll(id="trace")
            yield Vertical(id="indicator-bar")        # NEW — докнутая статус-строка
            with Horizontal(id="input-row"):
                ...
```

Пустой в простое (height auto → 0, без зазора); при старте прогона индикатор монтируется
сюда (height 1, `#trace` (`1fr`) ужимается на строку — одноразовый сдвиг на старте/конце
прогона, НЕ на каждый тик стрима).

### 2. Цель монтажа индикатора
`_show_thinking_indicator` ([:640-644](../../src/tui/screens/main.py#L640)) и
`_restore_terminal_indicator` ([:678](../../src/tui/screens/main.py#L678)) монтируют индикатор
в `#indicator-bar`, а не в `#trace`. Убрать сопутствующие `scroll-to-indicator` вызовы
([:630](../../src/tui/screens/main.py#L630), [:643-644](../../src/tui/screens/main.py#L643)) —
индикатор теперь всегда виден, доводить до него вид не нужно.

### 3. Развязать `#trace` от индикатора
`_trace_mount` ([:752-753](../../src/tui/screens/main.py#L752)) — убрать ветку
`before=self._thinking`; строки трейса (стрим/каноника/тулзы) просто `trace.mount(widget)`.
(Инвариант «индикатор последний в `#trace`» больше не нужен — его там нет.)

### 4. CSS (`styles.tcss`)
- `#indicator-bar { height: auto; }` (0 когда пусто).
- `.thinking-indicator` — убрать `margin-top: 1` (для докнутой строки зазор-сверху не нужен);
  выровнять левый край индикатора по колонке контента `#trace` (тот же left-padding, что у
  строк трейса) — чтобы статус не «прыгал» по горизонтали относительно реплик.

### 5. Жизненный цикл — без изменений
`set_state` (thinking/processing/validating/compressing/terminal), hide/destroy, персист
терминального итога, resume — как сейчас; меняется только родитель. Анимация (свой 0.1 c
таймер) не трогается.

## Изменение UX (принимаем)

Индикатор становится **фиксированной статус-строкой**: остаётся виден, когда юзер отскроллил
`#trace` вверх читать историю (показывает «всё ещё думаю…»). Раньше уезжал вместе с контентом.
Это прямое следствие выноса из скролла и согласовано.

## Регресс-поверхности

- Тесты, ищущие индикатор по типу (`query(ThinkingIndicator)` / `query_one`) — parent-agnostic,
  остаются зелёными.
- Тесты, проверяющие **родителя/порядок** индикатора относительно строк `#trace` (напр.
  ordering vs trace rows, «индикатор последний в `#trace`») — точечно обновить на новый регион.
- Превью (read-only) индикатора не имеет — не затронуто.
- Стрим-виджет: `_trace_mount` без `before=` — проверить, что стрим/каноника по-прежнему
  монтируются в `#trace` и автоскролл цел.

## Тесты (TUI → `uv run pytest`)

- Новый: после `_show_thinking_indicator` индикатор — ребёнок `#indicator-bar`, и его НЕТ среди
  детей `#trace`.
- Новый: строка стрима/каноники монтируется в `#trace`, индикатор ей не сосед (нет наложения
  по структуре).
- Регресс: `test_thinking_indicator*`, `test_trace_autoscroll`, `test_processing_indicator`,
  `test_resume_terminal_indicator` — зелёные (обновить те, что ассертят `#trace`-родительство/
  порядок).

## Вне scope
- Поведение/анимация самого индикатора, частота стрима (`STREAM_REFRESH_MS`) — не трогаем.
- Прочая верстка хрома (header/footer/input) — не трогаем.
