# Лендинг установки GigaCode Universal Agent (HTML) — дизайн

- **Дата:** 2026-06-21
- **Статус:** дизайн согласован (визуальная итерация через brainstorm-компаньон), готов к плану реализации
- **Источник контента:** `docs/install-quickstart-ru.md` (единственный источник истины по шагам)
- **Референс:** страница установки GigaCode CLI (`gigacode.sberbank.ru/#/instruction/CLI`) — зеркалим раскладку, бренд — наш

## 1. Цель и контекст

Сделать одностраничную HTML-инструкцию по установке нашего агента — аналог страницы установки GigaCode CLI (другая команда Сбера, корп-сеть), но в **нашем бренде** и под **нашу установку** (метод 2: `uv tool install git+https://…`). Назначение: передать руководителю/нетехническому пользователю; лежит в репозитории со ссылкой из README; в перспективе — хостинг в корп-сети.

«Зеркало» бренда: у GigaCode CLI акцент моно-фиолетовый; у нас — мультиколор-радуга (ретро-пиксельный бренд, скрин логотипа `UNIVERSAL AGENT`), уходящая в бирюзу/cyan (намеренно прочь от фиолетового Сбера).

## 2. Подход (архитектура артефакта)

- **Один самодостаточный `.html`** со встроенным CSS и JS, без сборки и сетевых зависимостей (offline — открывается двойным кликом).
- **Расположение:** `docs/install.html`. Ссылка из `readme.md` (рендерится при локальном клоне / будущем Pages; на git-хосте открывается как файл).
- **Шрифты offline:** Orbitron (только hero) встраивается как **base64-subset** под нужные глифы (`GIGACODE` + при необходимости подпись) — это единственный бренд-критичный шрифт. Код-блоки и текст — системные стеки (`ui-monospace/Consolas/Menlo`; `Inter`→`Segoe UI/-apple-system`), без встраивания. Это держит размер файла малым при сохранении бренда.
- **Никаких фреймворков**, ванильный CSS+JS.

## 3. Визуальная система (согласовано)

- **Фон:** `#0a0c10` + два мягких радиальных свечения (бирюза вверху-справа, зелёный слева-сверху).
- **Текст:** основной `#e8ebf1`, приглушённый `#8b93a3`, очень приглушённый `#6b727f`.
- **Акцент тела (единый):** бирюза `#3fd0c9` — номера шагов, ссылки, copy-иконки, активный таб, акценты таблицы.
- **Hero-градиент (вариант B, «как в TUI»):** `linear-gradient(90deg,#e0584a,#e89a3f,#dccf4a,#7ed957,#3fd0c9,#46e0d2)` — тёплый→холодный, заканчивается на cyan (без сине-фиолетового). Шрифт **Orbitron 900**, крупный (`clamp(40px,9vw,78px)`).
- **Шапка (логотип):**
  - шарик-маркер **②**: `radial-gradient(circle at 32% 30%,#9be88f,#3fd0c9 60%,#138f88)` + лёгкое свечение;
  - вордмарк: `GIGA` светлый (`#eef1f6`) + `CODE` градиент **①** `linear-gradient(90deg,#6fd07a,#3fd0c9,#46e0d2)` (зелёный→бирюза→cyan) — «зум» хвоста hero. Шрифт — жирный системный, letter-spacing 1.5px.
- **Панели/рамки:** панель `#0e1116`, рамки `#1f242d`/`#262c37`, скругления 9–14px.
- **Шрифты:** hero — Orbitron; код — моноширинный; остальное — Inter/системный.

## 4. Раскладка и компоненты (сверху вниз)

Контейнер `max-width:780px`, центрирован.

1. **Header:** шарик + вордмарк `GIGACODE` слева; nav справа (Документация / MCP / FAQ — пока заглушки-ссылки).
2. **Hero:** крупный градиентный `GIGACODE` + подпись `U N I V E R S A L   A G E N T` (разрядка).
3. **Заголовок:** хлебные крошки (`Главная / Установка / Быстрый старт`) + `H1` «Установка GigaCode Universal Agent» + лид-абзац (что это + получить адрес/токен у команды).
4. **OS-переключатель:** сегментированный pill `Windows | macOS / Linux`; влияет только на код-блок шага 1 (JS-тоггл).
5. **Шаги 1–6** (нумерованные, бирюзовый бейдж номера):
   1. Установить Git и uv (по ОС: Windows = winget+powershell; macOS/Linux = curl, git через xcode-select/apt) → перезапустить терминал.
   2. Установить агента: `uv tool install "git+https://gitverse.ru/gigacode-ai/background-agent"` + **callout-warn** про `--system-certs` в корп-сети; пояснение `gc-ua`/`gc-cli`.
   3. Создать конфиг: `gc-ua` → создаётся `~/.gc/config.yml`, останавливается с подсказкой.
   4. Вписать адрес и токен: yaml-блок (`backend.completions_url`, `use_ssl`, `chat_completion_headers.Authorization`, `agent.model`).
   5. Запустить: `gc-ua` / `gc-cli -q "…"` + **демо-скриншот** (предоставит пользователь; в макете — плейсхолдер).
   6. MCP-серверы (по желанию): `gc-mcp install / install <name> / list`, `gc-ua -a` + **таблица** (duckduckgo_search, office, science, computer, browser_playwright — с описаниями).
6. **Callout-info «Если не работает»:** git/uv не найдены; сертификаты → `--system-certs`; 401 → адрес/токен.
7. **Footer:** © 2026 GigaCode Universal Agent · поддержка (Телеграм/Сберчат).

**Код-блоки:** бордер-бокс, моно, простая подсветка (команда — бирюза, комментарий — приглушённый, ключи/строки yaml — синий/янтарный), **кнопка copy** справа-сверху.

## 5. Интерактив (ванильный JS)

- **OS-переключатель:** клик по табу → показывает соответствующий `.code[data-os]`, прячет другой; переключает активный стиль.
- **Copy-to-clipboard:** клик по иконке в код-блоке → `navigator.clipboard.writeText(<текст блока>)` → краткая визуальная отметка («✓»). Текст копируется без декоративных span'ов (брать `textContent`/data-атрибут).

## 6. Контент

Берётся 1:1 из `docs/install-quickstart-ru.md` (он — источник истины). Команды, поля конфига, таблица MCP, троблшутинг — синхронны с ним. При расхождении правится сначала md, затем страница.

**Заглушки для финализации (вне дизайна, на этапе сборки/наполнения):**
- реальный демо-скриншот `gc-ua` (даёт пользователь);
- реальные адрес/токен/модель — остаются плейсхолдерами (выдаёт команда GigaCode);
- nav-ссылки (Документация/MCP/FAQ) — указать реальные или убрать, если нет целей.

## 7. Вне scope

- Многостраничный сайт, выбор IDE, changelog/FAQ-страницы (у референса они есть — нам не нужны).
- i18n (только RU).
- Реальный деплой/хостинг в корп-сети (отдельно, позже) — артефакт к нему готов (самодостаточный файл).
- Точная пиксель-арт реконструкция логотипа (решено: Orbitron-градиент вместо попиксельной отрисовки).

## 8. Критерии приёмки

- Файл `docs/install.html` открывается **двойным кликом без сети** и выглядит как согласованный макет (тёмная тема, hero-градиент B, шапка с шариком ② и CODE ①, бирюзовое тело).
- OS-переключатель и copy-кнопки работают.
- Контент совпадает с `install-quickstart-ru.md`.
- Адаптивность: читаемо на узком экране (один контейнер, `clamp()` на крупных шрифтах).
- Нет внешних запросов (шрифт встроен/системный), нет JS-ошибок в консоли.

- Нет (hero=B, CODE=①, шарик=②, шрифт hero=Orbitron — все зафиксированы). Демо-скрин и nav-цели — наполнение, не дизайн.
