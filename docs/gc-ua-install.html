Установка GigaCode Universal Agent

Агент для выполнения задач в терминале. Установка одной командой, без клонирования репозитория. Перед началом получите у команды GigaCode адрес сервера и токен доступа — понадобятся на шаге 4.

  1. 1

    Установить Git и uv

    Одноразовый шаг. Откройте терминал и выполните команды для своей системы.

    winget install Git.Git powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
    xcode-select --install # Git curl -LsSf https://astral.sh/uv/install.sh | sh # uv
    sudo apt install -y git # Git (Debian/Ubuntu) curl -LsSf https://astral.sh/uv/install.sh | sh # uv

    После установки перезапустите терминал.

  2. 2

    Установить агента

    uv tool install "git+https://gitverse.ru/gigacode-ai/universal-agent"
    !
    В корпоративной сети Сбера добавьте в конец флаг --system-certs — иначе установка прервётся на проверке сертификатов.

    Устанавливаются две команды: gc-ua — основной режим с интерфейсом, и gc-cli — командная строка без интерфейса (разовые запросы, скрипты, автоматизация).

  3. 3

    Запустить и настроить

    gc-ua

    Первый запуск открывает мастер настройки: адрес сервера → токен → модель → MCP-серверы. Впишите адрес и токен, полученные у команды GigaCode; модель предложится списком с сервера. После подтверждения настройки сохранятся в файл ~/.gc/config.yml (C:\Users\$USER\.gc\config.yml)~/.config/gc/config.yml, и агент откроется.

    Мастеру нужен интерактивный терминал. Если запускаете без него (SSH без tty, CI) — агент подскажет, что вписать в config.yml вручную.

  4. 4

    Изменить настройки позже

    Команда /settings в интерфейсе агента — адрес сервера, токен, модель, MCP-серверы, обновление. Менять конфиг руками не нужно; файл лежит в ~/.gc/config.yml~/.config/gc/config.yml, если всё же захотите.

  5. 5

    MCP-серверы — по желанию

    Подключаемые расширения: поиск, документы, браузер и др. Управление в интерфейсе агента: /settings → MCP-серверы — установить, включить, обновить, удалить. После установки подключаются автоматически.

    Те же действия командой — для скриптов и автоматизации:

    gc-mcp install # все рекомендованные gc-mcp install duckduckgo_search # один по имени gc-mcp list # доступные / установленные gc-mcp remove duckduckgo_search # удалить по имени gc-mcp remove --all # удалить все gc-ua -a # запуск со всеми
    MCP-серверЧто умеет
    duckduckgo_searchПоиск в интернете — веб-страницы и новости.
    officeЧтение и создание Word, Excel, PowerPoint.
    scienceПоиск научных публикаций (PubMed, arXiv и др.).
    computerАвтоматизация Windows-интерфейса (только Windows).
    browser_playwrightУправление браузером — сайты, формы, клики.
  6. 6

    Обновление и удаление — когда понадобится

    Агент сам проверяет новую версию при запуске и показывает уведомление.
    Обновить — в интерфейсе: /settings → Обновление, или командой:

    gc-ua --update
    !
    В корпоративной сети Сбера один раз пропишите в конфиг update.extra_args: ["--system-certs"] — агент подставит флаг при каждом обновлении, иначе оно прервётся на сертификатах.

    После обновления агент может попросить дописать новые настройки в ваш конфиг — gc-ua --sync-config (то же есть в /settings → Обновление).

    Удалить — сначала MCP, затем сам агент (иначе gc-mcp исчезнет вместе с ним):

    gc-mcp remove --all # если ставили MCP-серверы uv tool uninstall gc-ua

    Полностью стереть конфиг, токены и данные — необязательно:

    Remove-Item -Recurse -Force "$env:USERPROFILE\.gc"
    rm -rf ~/.config/gc ~/.local/share/gc ~/.local/state/gc ~/.cache/gc
i
Если не работает.
  • git/uv не найдены → повторите шаг 1, перезапустите терминал.
  • uv/gc-ua не видны → uv tool update-shell + перезапуск (все ОС). Без перезапуска: macOS/Linux source ~/.local/bin/env; Windows (PowerShell) $env:Path = "$env:USERPROFILE\.local\bin;$env:Path".
  • Падает на сертификатах → флаг --system-certs.
  • Ошибка 401 → проверьте адрес и токен в конфиге.
