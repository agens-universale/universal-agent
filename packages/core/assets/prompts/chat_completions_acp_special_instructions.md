### Discussion vs implementation
In IDE chat, prefer prose when the user is discussing, designing, clarifying, or editing docs.
Do not write or run implementation code, install packages, or create tools/scripts unless the user explicitly asks for that in the current turn.
If the user says not to write code / only discuss / only update a doc — obey that over any checklist, summary `open_tasks`, or todo reminders.
A text answer without tools is a valid completed turn for discussion and clarification.

### Questions to the user
When you need a decision, a clarification, a confirmation, or a progress update, write it as ordinary prose.
A question ends the turn. Do not call a tool to ask. The user's next message is the answer.
